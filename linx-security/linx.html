Overview

Making Security Feel Like Progress

Linx Security needed to solve a familiar enterprise problem: how do you get people to actually engage with security training? The answer was gamification — a level-based system that gave users a clear sense of progression, achievement, and reward. The creative work spanned brand character development, moodboard exploration, and a full visual system for the level UI.

Approach

Four Levels, One Coherent System

The design moved through four distinct levels, each with its own moodboard, color language, and visual personality — escalating in complexity and prestige as users advanced. Level 1 established the foundational system; Level 4 felt like an earned achievement. The visual progression was deliberate: users should feel the difference between where they started and where they ended up.
